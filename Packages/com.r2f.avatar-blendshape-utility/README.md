# Avatar Blendshape Utility

Avatar Blendshape Utility is a multilingual Unity Editor tool for inspecting and editing blendshapes on avatar models.

## Features

- Finds and displays blendshapes from a selected avatar model.
- Provides live scene and isolated 3D previews.
- Supports blendshape search, grouping and modified-value filtering.
- Saves and loads local presets.
- Exports the current blendshape values as a Unity animation clip.
- Includes English, Japanese, Korean and Chinese UI options.
- Includes dark and light themes.

## Open the tool

In the Unity menu, select:

```text
R2F > Avatar Blendshape Utility
```

## Requirements

- Unity 2022.3 or newer within the supported VRChat project line.
- No direct VRChat SDK dependency is required.
