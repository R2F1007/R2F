# Changelog

All notable changes to Avatar Blendshape Utility are documented here.

## [1.1.0] - 2026-11-13

- Add an animation export choice between non-zero blendshapes and all blendshapes, including zero values.
- Give additional blendshape list width to the name column while keeping a comfortable 160-pixel slider track when space permits.
- Render scene-backed previews using a separate hidden camera so resizing Scene View cannot retain a preview aspect ratio.

## [1.0.0] - 2026-08-31

- Initial VPM release.
- Migrated the existing Unity editor script into an editor-only UPM/VPM package.
- Added package metadata and an assembly definition.
- Preserved the original script GUID for migration compatibility.
